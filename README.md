# vyronyx-digests
SHA-256 fingerprints of frozen test documents from VyroNyx's KingMaker Protocol (Angel Eyes AIR and ZERO, CAL, Dodona). Each manifest proves a document existed, unchanged, before the test it governs was run. No data, code or results are stored here.

The one workflow here (`public-dataset-fetch.yml`) only lists or downloads files from public, open-licence datasets (into a short-lived build artifact); nothing it fetches is stored in this repository.
